## Installation and setup

```ts
import { createSdk } from "@offerhub/sdk";

const sdk = createSdk({ baseUrl: "https://api.offer-hub.tech" });

// All order methods are accessed through an authenticated user context.
const user = sdk.asUser(token);
```

Every method below is called on the object returned by `sdk.asUser(token)`.

## Orders

### Create an order

```ts
const order = await sdk.asUser(token).orders.create(payload);
```

Creates a new order. You **must** supply an `Idempotency-Key` in the request options to prevent duplicate orders on retry.

```ts
const order = await sdk.asUser(token).orders.create(
  {
    offerId: "offer_abc123",
    amount: { value: "250.00", currency: "USD" },
    milestones: [
      { ref: "design", label: "Design mockups", percentage: 40 },
      { ref: "final",  label: "Final delivery",  percentage: 60 },
    ],
  },
  { idempotencyKey: "my-unique-key-001" }
);
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `offerId` | `string` | âœ“ | ID of the offer being purchased |
| `amount` | `{ value: string; currency: string }` | âœ“ | Order total |
| `milestones` | `Milestone[]` | â€” | Optional milestone breakdown (percentages must sum to 100) |

**Returns:** `Order`

### Reserve funds

```ts
await sdk.asUser(token).orders.reserve(orderId);
```

Transitions the order from `ORDER_CREATED` to `FUNDS_RESERVED`. Must be called after the escrow transaction is submitted.

| Parameter | Type | Description |
|-----------|------|-------------|
| `orderId` | `string` | ID of the order |

**Returns:** `Order`

---

### Cancel an order

```ts
await sdk.asUser(token).orders.cancel(orderId);
```

Cancels the order and transitions it to `CLOSED`.

> **Important:** An order can only be cancelled from the `ORDER_CREATED` or `FUNDS_RESERVED` status. Attempting to cancel from any other status will return an error. There is no `CANCELLED` status â€” the terminal state is `CLOSED`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `orderId` | `string` | ID of the order to cancel |

**Returns:** `Order`

## Escrow

Escrow operations follow a **prepare â†’ sign â†’ submit** flow. The prepare step returns an unsigned XDR transaction that your client signs with the user's key before submitting.

### Prepare escrow creation

```ts
const { xdr } = await sdk.asUser(token).escrow.prepare(orderId);
```

Returns an unsigned XDR transaction for creating the escrow account.

| Parameter | Type | Description |
|-----------|------|-------------|
| `orderId` | `string` | ID of the order |

**Returns:** `{ xdr: string }`

---

### Prepare escrow fund

```ts
const { xdr } = await sdk.asUser(token).escrow.fundPrepare(orderId);
```

Returns an unsigned XDR transaction for funding the escrow.

| Parameter | Type | Description |
|-----------|------|-------------|
| `orderId` | `string` | ID of the order |

**Returns:** `{ xdr: string }`

---

### Submit signed escrow transaction

```ts
await sdk.asUser(token).escrow.submit(orderId, signedXdr);
```

Submits the signed XDR transaction to the network. Supply an `Idempotency-Key` to safely retry failed submissions.

```ts
await sdk.asUser(token).escrow.submit(
  orderId,
  signedXdr,
  { idempotencyKey: "escrow-submit-001" }
);
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `orderId` | `string` | ID of the order |
| `signedXdr` | `string` | Base64-encoded signed XDR transaction |

**Returns:** `{ txHash: string }`

## Resolution

Resolution methods handle releasing funds, issuing refunds, and opening disputes. Like escrow, the prepare endpoints return unsigned XDR for client-side signing.

### Prepare release

```ts
const { xdr } = await sdk.asUser(token).resolution.releasePrepare(orderId);
```

Returns an unsigned XDR transaction for releasing escrow funds to the seller.

| Parameter | Type | Description |
|-----------|------|-------------|
| `orderId` | `string` | ID of the order |

**Returns:** `{ xdr: string }`

---

### Prepare refund

```ts
const { xdr } = await sdk.asUser(token).resolution.refundPrepare(orderId);
```

Returns an unsigned XDR transaction for refunding escrow funds to the buyer.

| Parameter | Type | Description |
|-----------|------|-------------|
| `orderId` | `string` | ID of the order |

**Returns:** `{ xdr: string }`

---

### Prepare dispute

```ts
const { xdr } = await sdk.asUser(token).resolution.disputePrepare(orderId);
```

Returns an unsigned XDR transaction required before opening a dispute.

| Parameter | Type | Description |
|-----------|------|-------------|
| `orderId` | `string` | ID of the order |

### Open a dispute

```ts
await sdk.asUser(token).resolution.dispute(orderId, payload);
```

Opens a dispute on the order. Call `resolution.disputePrepare` first and include the resulting signed XDR in the payload.

```ts
await sdk.asUser(token).resolution.dispute("order_xyz789", {
  reason: "NOT_DELIVERED",
  signedXdr: "<signed-xdr-from-prepare>",
  description: "The seller has not delivered the agreed work.",
});
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `reason` | `"NOT_DELIVERED" \| "QUALITY_ISSUE" \| "OTHER"` | âœ“ | Reason for the dispute |
| `signedXdr` | `string` | âœ“ | Signed XDR from `disputePrepare` |
| `description` | `string` | â€” | Optional free-text description |

**Returns:** `Dispute`

## Full example: place and fund an order

```ts
import { createSdk } from "@offerhub/sdk";

const sdk = createSdk({ baseUrl: "https://api.offer-hub.tech" });

async function placeAndFundOrder(token: string) {
  const user = sdk.asUser(token);

  // 1. Create the order
  const order = await user.orders.create(
    {
      offerId: "offer_abc123",
      amount: { value: "500.00", currency: "USD" },
    },
    { idempotencyKey: "order-create-abc123" }
  );

  // 2. Prepare the escrow account
  const { xdr: createXdr } = await user.escrow.prepare(order.id);
  const signedCreateXdr = await signWithUserKey(createXdr); // your signing logic

  await user.escrow.submit(order.id, signedCreateXdr, {
    idempotencyKey: "escrow-create-abc123",
  });

  // 3. Fund the escrow
  const { xdr: fundXdr } = await user.escrow.fundPrepare(order.id);
  const signedFundXdr = await signWithUserKey(fundXdr);

  await user.escrow.submit(order.id, signedFundXdr, {
    idempotencyKey: "escrow-fund-abc123",
  });

  // 4. Reserve funds â€” order transitions to FUNDS_RESERVED
  await user.orders.reserve(order.id);

  return order;
}
```

## Order status reference

| Status | Description |
|--------|-------------|
| `ORDER_CREATED` | Order created, awaiting escrow setup |
| `FUNDS_RESERVED` | Escrow funded and funds locked |
| `IN_PROGRESS` | Work has started |
| `DELIVERED` | Seller marked the order as delivered |
| `COMPLETED` | Buyer accepted delivery; payout triggered |
| `DISPUTED` | A dispute has been opened |
| `UNDER_REVIEW` | Dispute under admin review |
| `RESOLVED` | Dispute resolved |
| `CLOSED` | Order cancelled and closed |
