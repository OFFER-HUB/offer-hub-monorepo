OFFER-HUB order settlement uses USDC. A seller can receive a released order payout to a local bank account through BlindPay when their country is supported.

## Supported payout corridors

The supported corridors are exactly Brazil (`BR`), Mexico (`MX`), Argentina (`AR`), and Colombia (`CO`). The payout corridor follows the seller's country. An unsupported country or a missing bank account for that corridor returns an error.

The corridor determines which local payout route BlindPay uses; it does not change the USDC-denominated order settlement amount. Bank-account quotes have a minimum of **5.00 USD**. Some payment rails have a higher minimum, and receiver transaction volume limits also apply. See [BlindPay's API documentation](https://docs.blindpay.com/) for current values and the [seller payout guide](/docs/guide/withdrawals) for payout steps.
