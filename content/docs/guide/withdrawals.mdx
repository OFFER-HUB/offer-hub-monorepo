OFFER-HUB pays a seller's released order in USDC to a local bank account through BlindPay. The payout corridor follows the seller's country. The supported corridors are exactly Brazil (`BR`), Mexico (`MX`), Argentina (`AR`), and Colombia (`CO`). A seller in an unsupported country, or without a bank account for their corridor, cannot prepare a payout.

See the [KYC API reference](/docs/api-reference/kyc) and [bank accounts API](/docs/api-reference/bank-accounts) for setup operations. The exact prepare and submit request fields are defined by the installed `@offerhub/sdk` 3.0.0 types; the verified public issue contract does not publish their property names. The server does not sign for the user.

## Payout statuses

| Status | Meaning |
| --- | --- |
| `PENDING` | Payout has been created and is waiting to be processed. |
| `PROCESSING` | BlindPay is processing the payout. |
| `COMPLETED` | Payout completed. |
| `FAILED` | Payout failed; funds are returned and the payout can be retried. |
| `REFUNDED` | Funds have been returned. |
| `ON_HOLD` | Payout is on hold. |
| `AWAITING_SIGNATURE` | The unsigned transaction is awaiting the seller's signature. |

BlindPay events handled by the Orchestrator are `payout.new`, `payout.update`, `payout.complete`, `payout.completed`, `payout.failed`, `payout.on_hold`, and `payout.refunded`. These events update the payout status. Integrators can read the latest status from the payout endpoint or the event feed.

<Callout type="note">
  If you self-host the Orchestrator, register its BlindPay webhook in your BlindPay dashboard. Use the webhook configuration provided for your own deployment; this guide does not prescribe a hostname.
</Callout>

## Limits and fees

BlindPay bank-account quotes have a minimum of **5.00 USD**. Some payment rails have a higher minimum; BlindPay rejects payouts below that rail's minimum with `PAYOUTS_AMOUNT_BELOW_MINIMUM`. Each receiver also has a transaction volume limit. When the limit is exceeded, BlindPay returns `LIMITS_VOLUME_EXCEEDED`; operators can request a higher limit through BlindPay's limit-increase process.

Current limits can change. Check [BlindPay's API documentation](https://docs.blindpay.com/) for current values. BlindPay fees are set by the operator's BlindPay agreement; no fee amounts are listed here. See [BlindPay pricing and documentation](https://docs.blindpay.com/).
