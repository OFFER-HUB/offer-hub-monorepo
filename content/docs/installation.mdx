## Option 1: Setup Wizard <Badge variant="success">Recommended</Badge>

`create-offer-hub-orchestrator` is a one-command interactive setup wizard. It configures your `.env`, runs database migrations, and bootstraps the platform user — so you can skip the manual steps entirely.

<Callout type="tip">
  This is the fastest way to get a working Orchestrator. Run the wizard, answer the prompts, and you'll have a running API in under 2 minutes.
</Callout>

### Step 1 — Clone and install

<CommandLine>git clone https://github.com/OFFER-HUB/OFFER-HUB.git && cd OFFER-HUB && npm install</CommandLine>

### Step 2 — Run the setup wizard

<CommandLine>npx create-offer-hub-orchestrator</CommandLine>

The wizard prompts for:

| Prompt | Description |
|--------|-------------|
| API Port | Default: `4000` |
| PostgreSQL URL | Use the **pooler** URL (port `6543`) for Supabase |
| Redis URL | `redis://` or `rediss://` for TLS connections |
| Payment provider | `crypto` (Stellar/USDC, default) or `airtm` |
| Stellar network | `testnet` for development, `mainnet` for production |
| Trustless Work API key | From [dapp.trustlesswork.com](https://dapp.trustlesswork.com) |
| Trustless Work Webhook Secret | From your TW dashboard |
| Public URL | Your server's HTTPS URL (used for webhook callbacks) |
| Run migrations? | Yes — applies all pending DB migrations |
| Generate API key? | Optional — requires the server to be running |

The wizard then automatically:

1. Generates a secure `OFFERHUB_MASTER_KEY`
2. Generates a secure `WALLET_ENCRYPTION_KEY` (crypto mode)
3. Writes `.env` with all values filled in
4. Runs `prisma migrate deploy`
5. Runs `npm run bootstrap` — creates the platform Stellar wallet and writes `PLATFORM_USER_ID` into `.env`

### Step 3 — Start the API

<CommandLine>npm run dev</CommandLine>

The API starts on `http://localhost:4000`.

### Step 4 — Verify installation

<CommandLine>curl http://localhost:4000/api/v1/health</CommandLine>

```json
{
  "status": "healthy",
  "timestamp": "2026-02-25T12:00:00.000Z",
  "services": {
    "database": "connected",
    "redis": "connected"
  }
}
```

<Callout type="warning">
  **Back up `WALLET_ENCRYPTION_KEY` immediately.** If you lose it, all user wallets become unrecoverable. Store it in a secrets manager (Railway Variables, AWS Secrets Manager, or 1Password). Do not commit `.env` to git.
</Callout>

<Callout type="note">
  The wizard is **idempotent for bootstrap** — safe to re-run. It will ask before overwriting an existing `.env`. Run with `testnet` first; switch to `mainnet` only when ready for production.
</Callout>

## Option 2: Full Local Setup

Use this path when you need full manual control — custom Docker networks, CI/CD pipelines, or environments where running an interactive wizard isn't appropriate.

### Prerequisites

- **Node.js** v20 or later ([nodejs.org](https://nodejs.org))
- **npm** v10 or later
- **Docker** and **Docker Compose** (for PostgreSQL and Redis)
- A [Trustless Work](https://trustlesswork.com) API key (for escrow)

<Callout type="note">
  You can also use managed services like [Supabase](https://supabase.com) for PostgreSQL and [Upstash](https://upstash.com) for Redis instead of Docker.
</Callout>

### Step 1 — Clone the Repository

<CommandLine>git clone https://github.com/OFFER-HUB/OFFER-HUB.git && cd OFFER-HUB</CommandLine>

### Step 2 — Install Dependencies

<CommandLine>npm install</CommandLine>

### Step 3 — Start Infrastructure

Start PostgreSQL and Redis using Docker Compose:

<CommandLine>docker compose up -d</CommandLine>

This starts:
- PostgreSQL on port `5432`
- Redis on port `6379`

### Step 4 — Configure Environment

Copy the example environment file:

<CommandLine>cp .env.example .env</CommandLine>

Edit `.env` with your values. The minimum required variables for local development:

```env
# Server
NODE_ENV=development
PORT=4000

# Database (Docker defaults)
DATABASE_URL=postgresql://offerhub:offerhub_password@localhost:5432/offerhub_db
DIRECT_URL=postgresql://offerhub:offerhub_password@localhost:5432/offerhub_db

# Redis (Docker default)
REDIS_URL=redis://localhost:6379

# Payment Provider
PAYMENT_PROVIDER=crypto
WALLET_ENCRYPTION_KEY=your-32-byte-hex-key

# Master Key (for creating API keys)
OFFERHUB_MASTER_KEY=your-secure-master-key

# Trustless Work (get from trustlesswork.com)
TRUSTLESS_API_KEY=your_trustless_api_key
TRUSTLESS_API_URL=https://dev.api.trustlesswork.com

# Stellar (testnet defaults)
STELLAR_NETWORK=testnet
STELLAR_HORIZON_URL=https://horizon-testnet.stellar.org
STELLAR_USDC_ASSET_CODE=USDC
STELLAR_USDC_ISSUER=GBBD47IF6LWK7P7MDEVSCWR7DPUWV3NY3DTQEVFL4NAT4AQH3ZLLFLA5
```

<Callout type="warning">
  Generate your `WALLET_ENCRYPTION_KEY` with: `openssl rand -hex 32`

  Store this key securely — losing it makes wallet private keys unrecoverable.
</Callout>

### Step 5 — Run Database Migrations

Generate the Prisma client and apply migrations:

<CommandLine>npm run prisma:generate && npm run prisma:migrate</CommandLine>

### Step 6 — Bootstrap Platform User

Create the internal platform user required for escrow operations:

<CommandLine>npm run bootstrap</CommandLine>

### Step 7 — Start the API

<CommandLine>npm run dev</CommandLine>

The API starts on `http://localhost:4000`.

### Step 8 — Verify Installation

Test that everything is working:

<CommandLine>curl http://localhost:4000/api/v1/health</CommandLine>

You should see:

```json
{
  "status": "healthy",
  "timestamp": "2026-02-25T12:00:00.000Z",
  "services": {
    "database": "connected",
    "redis": "connected"
  }
}
```

## Option 3: Using the SDK Only

If you want to integrate with an existing OFFER-HUB Orchestrator instance (hosted by you or a partner), you only need the SDK:

<CommandLine>npm install @offerhub/sdk</CommandLine>

Then configure it in your code:

```typescript
import { OfferHubSDK } from '@offerhub/sdk';

const sdk = new OfferHubSDK({
  apiUrl: 'https://your-orchestrator-url.com',
  apiKey: 'ohk_live_your_api_key'
});

// Create a user
const user = await sdk.users.create({
  externalUserId: 'user-123',
  email: 'buyer@example.com'
});
```

See the [SDK Guide](/docs/sdk/quick-start) for complete documentation.

## Creating Your First API Key

Once the server is running, create an API key using your master key.

### Option A: Using the CLI (Recommended)

The `@offerhub/cli` is the fastest way to create an API key:

<CommandLine>npm install -g @offerhub/cli</CommandLine>

<CommandLine>offerhub keys create</CommandLine>

This runs an interactive wizard that prompts for user ID, scopes, and key name. See the [CLI Guide](/docs/guide/cli) for all available commands.

### Option B: Using curl

```bash
curl -X POST http://localhost:4000/api/v1/auth/api-keys \
  -H "Authorization: Bearer YOUR_OFFERHUB_MASTER_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "My Marketplace", "scopes": ["read", "write"]}'
```

Response:

```json
{
  "data": {
    "id": "key_abc123",
    "key": "ohk_live_xxxxxxxxxxxx",
    "name": "My Marketplace",
    "scopes": ["read", "write"]
  }
}
```

<Callout type="danger">
  Save the `key` value immediately — it's only shown once. Use this key for all subsequent API calls.
</Callout>

## Troubleshooting

### Database Connection Failed

Make sure Docker is running and the containers are up:

<CommandLine>docker compose ps</CommandLine>

If containers aren't running, start them:

<CommandLine>docker compose up -d</CommandLine>

### Prisma Migration Errors

If you see migration errors, try resetting the database:

<CommandLine>npm run prisma:migrate reset</CommandLine>

<Callout type="warning">
  This deletes all data. Only use in development.
</Callout>

### Port Already in Use

If port 4000 is already in use, change the `PORT` in your `.env` file or stop the conflicting service.
